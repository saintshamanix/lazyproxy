# Обновление до 3x-ui 3.9.0

[README](../README.ru.md) · [English](UPGRADE-3.9.0.md)

**Используйте штатное обновление в панели.** Повторная установка LazyProxy и привязка второго IP не нужны.
[Границы проверки](VALIDATION.md).

## Порядок

1. Создайте снимок VPS и скачайте резервную копию БД панели. Одна БД не включает nginx, сертификаты, Netplan и настройки systemd.
2. Выберите **3.9.0** в обновлении панели и дождитесь завершения. Не запускайте LazyProxy параллельно. При перезапуске соединения прервутся.
3. Откройте прежний HTTPS-адрес. Проверьте версию панели, подписки и реальный трафик через используемые протоколы и исходящие.
4. На VPS с двумя IP проверьте оба UDP-адреса из таблицы. Сохраните существующий Netplan и зависимость запуска x-ui от наличия адресов.

| Схема | Hysteria2 | AmneziaWG |
|---|---|---|
| Один IP | IP1:443/UDP | IP1:51820/UDP |
| Два IPv4 | IP1:443/UDP | IP2:443/UDP |

При двух IP ни один UDP/443 listener не должен слушать все адреса.
У пустого AWG-входящего сокет может появиться только после добавления клиента.

## Если возникли вопросы при обновлении

- При запросе SSL панели выберите **Skip SSL / behind reverse proxy**. Сохраните `127.0.0.1:2053`, прежний путь панели и TLS на nginx.
- Если веб-обновление остановилось на интерактивном запросе, перед повтором проверьте журнал по SSH.
- 3.9.0 мигрирует БД и параметры исходящих WireGuard. Для отката восстановите снимок либо старые бинарники **вместе с** соответствующей БД.
- Для WARP на VPS без рабочего IPv6 проверьте `streamSettings.sockopt.domainStrategy` после миграции и реальный трафик.
- Пересекающиеся диапазоны клиентов AWG могут мешать сохранению; исправляйте адреса клиентов, а не маршруты по умолчанию исходящего WireGuard.
- Перед включением еженедельного продления обновите все узлы кластера.

```bash
sudo /usr/local/x-ui/x-ui -v
sudo systemctl is-active x-ui nginx single443-firewall
sudo ss -lnup
sudo nginx -t
sudo journalctl -u x-ui --since "10 minutes ago" --no-pager
```

Обновление панели не меняет `/opt/single443`.
Последующее [обновление LazyProxy](OPERATIONS.ru.md#lazyproxy-update) необязательно; используйте актуальный репозиторий.
