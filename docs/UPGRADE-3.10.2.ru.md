# Обновление до 3x-ui 3.10.2

[README](../README.ru.md) · [English](UPGRADE-3.10.2.md)

Для существующих серверов LazyProxy с 3.10.0 и одним или двумя публичными IP.

1. Сохраните свежую резервную копию панели вне VPS; для полного отката сохраните снимок VPS.
2. Подключитесь через другой сервер либо напрямую по SSH. Выберите **3.10.2** в штатном обновлении панели и дождитесь завершения. При перезапуске соединения могут прерваться.
3. Проверьте состояние панели и Xray, обновите подписки и проверьте реальный трафик используемых протоколов. На сервере с двумя IP отдельно проверьте адрес и порт AWG.
4. Если включена маршрутизация INCY/Happ, после обновления подписок проверьте получение нужного профиля каждым приложением.

Повторная установка, привязка IP2 и запуск `add-masque.sh` для этого обновления не нужны. Обновление компонентов LazyProxy — отдельная операция.

Xray остаётся **26.10.10**. Ограничения авторизации и экспорта MASQUE сохраняются; совместимость с Shadowrocket этим обновлением не подтверждена.

Для отката восстановите согласованные версии бинарников панели и БД либо снимок VPS. Старые резервные копии LazyProxy отражают состояние перед соответствующими запусками скрипта.
