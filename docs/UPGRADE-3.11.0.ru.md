# Обновление до 3x-ui 3.11.0

[README](../README.ru.md) · [English](UPGRADE-3.11.0.md)

Для существующих серверов LazyProxy с 3.10.2 и одним или двумя публичными IP.

1. Сохраните свежую резервную копию панели вне VPS; для полного отката сохраните снимок VPS.
2. Подключитесь через другой сервер либо напрямую по SSH. Выберите **3.11.0** в штатном обновлении панели и дождитесь завершения.
3. Проверьте версию панели и запущенного Xray. В комплект входит **Xray 26.10.21** — обновление безопасности, заменяющее отозванные версии 26.10.10/26.10.17.
4. Для этого обновления сохраните встроенный режим AmneziaWG. Новый опциональный режим ядра Linux работает через NAT и требует отдельной проверки маршрутизации и firewall; проверки встроенного AWG в LazyProxy его не покрывают.
5. Обновите подписки, проверьте внешние адреса/порты и реальный трафик используемых протоколов. На сервере с двумя IP отдельно проверьте AWG на дополнительном IP. Если включена маршрутизация INCY/Happ, проверьте профиль каждого приложения.

Повторная установка, привязка IP2 и запуск `add-masque.sh` для этого обновления не нужны. Обновление компонентов LazyProxy — отдельная операция.

В релизе ускорена отправка данных встроенного AmneziaWG и исправлено обновление импортированных Hosts при изменении External Proxy. Совместимость MASQUE с Shadowrocket не подтверждена: входящий MASQUE в Xray 26.10.21 по-прежнему использует HTTP Basic авторизацию. Создание входящего не подтверждает совместимость клиента.

Для отката восстановите согласованный снимок панели, БД и ядра. Отозванные сборки Xray не рекомендуются для постоянной эксплуатации. Старые резервные копии LazyProxy отражают состояние перед соответствующими запусками скрипта.
